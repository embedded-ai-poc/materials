# 유형별 아웃라인 패턴

## 유형 A: 시스템/아키텍처

```
1. 현재 상황과 문제점
2. 요구사항 분석
3. [아키텍처 탭] 시스템 설계 ← 별도 탭, 전체 너비
4. 핵심 컴포넌트 상세
5. 구현 결과 / 성과
6. 향후 계획
```

| 항목 | 값 |
|------|-----|
| 테마 | backstage, dark |
| 레이아웃 | 아키텍처 전용 탭 + 전체 너비 |
| 시각 요소 | HTML/CSS 아키텍처 다이어그램 |
| 리서치 중점 | 공식 문서, 기술 스펙 |

---

## 유형 B: 개념/기술 설명

```
1. [주제]란 무엇인가?
2. 왜 필요한가? (배경/동기)
3. 핵심 원리 / 동작 방식
4. 주요 구성 요소
5. 실제 활용 예시
6. 시작하기 / 다음 단계
```

| 항목 | 값 |
|------|-----|
| 테마 | AI→backstage, 개발도구→dark |
| 레이아웃 | 텍스트+시각 2컬럼 균형 |
| 시각 요소 | 개념 다이어그램, 코드 예시 |
| 리서치 중점 | 정의, 원리, 예시, 공식 문서 |

---

## 유형 C: 트렌드/인사이트

```
1. 왜 지금 이 주제인가? (훅)
2. 현재 시장/기술 현황 [차트 중심]
3. 트렌드 #1: [제목]
4. 트렌드 #2: [제목]
5. 트렌드 #3: [제목]
6. 향후 전망 및 시사점
```

| 항목 | 값 |
|------|-----|
| 테마 | 주제 분위기에 맞게 |
| 레이아웃 | 데이터 시각화 중심, 차트 강조 |
| 시각 요소 | 통계 차트, 타임라인, 비교표 |
| 리서치 중점 | 최신 기사, 통계, 전망 보고서 |

---

## 유형 D: 튜토리얼/How-to

```
1. 완성 목표 (미리보기)
2. 사전 준비사항
3. Step 1: [단계명]
4. Step 2: [단계명]
5. Step 3: [단계명]
6. 완성! + 트러블슈팅
```

| 항목 | 값 |
|------|-----|
| 테마 | dark (코드 친화적) |
| 레이아웃 | 단계별 진행, 코드 블록 강조 |
| 시각 요소 | 스크린샷, 코드, 플로우차트 |
| 리서치 중점 | 공식 가이드, 코드 예시, 에러 해결 |

---

## 유형 E: 사례 연구

```
1. 우리는 이런 상황이었다
2. 마주한 도전과 선택지
3. 우리의 접근 방식
4. 실패와 피봇 (있다면)
5. 결과와 성과
6. 배운 것들 / 조언
```

| 항목 | 값 |
|------|-----|
| 테마 | casual (스토리에 맞게) |
| 레이아웃 | 스토리텔링 흐름, 이미지+인용 |
| 시각 요소 | 전후 비교, 타임라인, 성과 수치 |
| 리서치 중점 | 기업 블로그, 컨퍼런스 발표 |

---

## 유형 F: 의사결정/제안

```
1. 결정이 필요한 배경
2. 검토한 옵션들
3. 비교 분석 [테이블/Radar 차트]
4. 추천안과 근거
5. 예상 리스크와 대응
6. 다음 단계 제안
```

| 항목 | 값 |
|------|-----|
| 테마 | corporate, minimal |
| 레이아웃 | 비교표 중심, 깔끔한 구조 |
| 시각 요소 | 비교 테이블, Radar 차트, Pros/Cons |
| 리서치 중점 | 비교 벤치마크, 장단점, 가격 |

---

## 유형 G: 리서치/분석

```
1. 리서치 목적과 범위
2. 조사 방법론
3. 주요 발견 #1
4. 주요 발견 #2
5. 분석 및 해석
6. 결론 및 한계점
```

| 항목 | 값 |
|------|-----|
| 테마 | dark (분석적 느낌) |
| 레이아웃 | 데이터 테이블, 인용, 출처 강조 |
| 시각 요소 | 데이터 차트, 히트맵, 상관관계 |
| 리서치 중점 | 학술 자료, 데이터셋, 방법론 |

---

## 레이아웃 전략

| 콘텐츠 성격 | 권장 레이아웃 | CSS |
|------------|-------------|-----|
| 아키텍처 | 전체 너비 | `grid-template-columns: 1fr` |
| 개념+시각화 | 2컬럼 균형 | 기본값 |
| 코드 강조 | 코드 넓게 | `grid-template-columns: 1fr 2fr` |
| 차트 그리드 | 2x2 그리드 | `.grid-2` |
| 비교표 | 전체 너비 | `grid-template-columns: 1fr` |
| 핵심 수치 | 카드 그리드 | `.highlight-cards` |

---

## 섹션 전환 문구

| 전환 유형 | 예시 문구 |
|----------|----------|
| 개념 → 상세 | "이제 이것이 실제로 어떻게 동작하는지 살펴보겠습니다" |
| 문제 → 해결 | "그렇다면 이 문제를 어떻게 해결할 수 있을까요?" |
| 이론 → 사례 | "실제 적용 사례를 통해 확인해보겠습니다" |
| 현재 → 미래 | "앞으로 이 기술은 어떻게 발전할까요?" |
| 기술 → 비즈니스 | "이것이 비즈니스에 미치는 영향은 무엇일까요?" |

## 스토리 아크

```
[Hook] → [Context] → [Rising Action] → [Climax] → [Resolution]
 도입      배경         심화 전개        핵심 인사이트    결론
 5-10%   15-20%        40-50%          15-20%         10-15%
```
