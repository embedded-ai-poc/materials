4. 사용 가이드

✅ 기본 원칙

  • AS-IS는 legacy 클래스 사용 (회색 톤)
  • TO-BE는 success 클래스 사용 (초록/파랑 톤)
  • 상단에서 하단으로 흐르는 구조 유지
  • 화살표(arrow)로 계층 구분
  • system-container로 전체 시스템 감싸기
  • main-box로 주요 서비스 표현
  • inner-box로 세부 기능 표현

💡 커스터마이징 팁

  • 그리드 컬럼 수 조정: item-grid col-3, col-5, col-7
  • 색상 변형: inner-box에 ai, ops 클래스 추가
  • 연결 바 스타일: kafka, neutral, db 선택
  • 태그 스타일 일관성 유지

🎨 색상 일관성

  • AS-IS: 회색 계열 (#94a3b8, #e2e8f0, #fafafa)
  • TO-BE 메인: 파랑 계열 (#93c5fd, #bfdbfe, #eff6ff)
  • TO-BE 성공: 초록 계열 (#86efac, #f0fdf4)
  • 외부 서비스: 주황 계열 (#fdba74, #fed7aa)
  • AI: 보라 계열 (#a78bfa, #f3e8ff)
  • Ops: 청록 계열 (#5eead4, #ccfbf1)
